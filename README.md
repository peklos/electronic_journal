# 📚 Электронный журнал классного руководителя БППК

Современное WPF приложение для управления электронным журналом класса с поддержкой ролей учителя и ученика.

## ✨ Возможности

### Для учителя:
- 👥 **Управление учениками**: добавление, редактирование, удаление учеников
- 📊 **Управление оценками**: выставление оценок по предметам (5-балльная система)
- 📅 **Отметка посещаемости**: ведение учета присутствия учеников
- 🔍 **Фильтрация данных**: просмотр оценок и посещаемости по конкретному ученику
- 📈 **Информативные таблицы**: удобный просмотр всех данных

### Для ученика:
- 👤 **Личная информация**: просмотр своих данных
- 📚 **Оценки**: просмотр всех своих оценок по предметам
- 📅 **Посещаемость**: просмотр истории посещений
- 📊 **Статистика**: средний балл и общее количество оценок

## 🚀 Запуск приложения

### Вариант 1: Скачать готовый .exe файл

1. Перейдите в раздел [Releases](../../releases)
2. Скачайте файл `ElectronicJournal.exe`
3. Запустите файл на любом ПК с Windows

### Вариант 2: Сборка из исходного кода

#### Требования:
- Windows 10/11
- .NET 8.0 SDK

#### Команды для сборки:

```bash
# Клонировать репозиторий
git clone https://github.com/peklos/electronic_journal.git
cd electronic_journal

# Восстановить зависимости
dotnet restore ElectronicJournal/ElectronicJournal.csproj

# Собрать проект
dotnet build ElectronicJournal/ElectronicJournal.csproj -c Release

# Запустить
dotnet run --project ElectronicJournal/ElectronicJournal.csproj
```

#### Сборка в один .exe файл:

```bash
dotnet publish ElectronicJournal/ElectronicJournal.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
```

Файл будет находиться в папке `./publish/ElectronicJournal.exe`

## 🔐 Тестовый доступ

При первом запуске автоматически создаются демонстрационные данные:
- 5 учеников класса 9-А
- 5 предметов
- Оценки и записи посещаемости

### Учетные записи:

**Учитель (полный доступ):**
- **Логин**: `admin`
- **Пароль**: `admin`

**Ученик (просмотр своих данных):**
- **Логин**: `ivanov`
- **Пароль**: `ivanov`

После входа учителем можно:
- Просматривать и редактировать учеников
- Выставлять оценки
- Отмечать посещаемость
- Создавать новые аккаунты учеников

## 🛠 Технологии

- **Frontend**: WPF (Windows Presentation Foundation)
- **Backend**: .NET 8.0
- **База данных**: SQLite (встроенная, создается автоматически)
- **CI/CD**: GitHub Actions (автоматическая сборка в один .exe)

## 📊 База данных

База данных SQLite создается автоматически при первом запуске приложения. Включает таблицы:

- **Users** - пользователи системы
- **Students** - информация об учениках
- **Subjects** - предметы
- **Grades** - оценки
- **Attendance** - посещаемость

## 🎨 Особенности интерфейса

- Современный Material Design стиль
- Цветовое кодирование оценок:
  - 🟢 5 - Отлично (зеленый)
  - 🔵 4 - Хорошо (синий)
  - 🟡 3 - Удовлетворительно (оранжевый)
  - 🔴 2 - Неудовлетворительно (красный)
- Цветовое кодирование посещаемости:
  - 🟢 Присутствовал (зеленый)
  - 🔴 Отсутствовал (красный)
  - 🟡 По уважительной причине (оранжевый)

## 🔄 GitHub Actions

Проект настроен с автоматической сборкой через GitHub Actions. При каждом push в репозиторий:

1. Проект автоматически собирается
2. Создается единый .exe файл
3. Файл доступен для скачивания в разделе Actions → Artifacts
